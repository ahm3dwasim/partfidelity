# Teardown texture and model sources

Every texture is procedural: drawn in code by `textures.py` (Pillow and numpy) in the render container, or built from Blender noise nodes in `mats.py`. Every part is modelled by code in `parts.py`.

| Asset | Source | Licence |
|---|---|---|
| PCB, chip markings, key legends, wallpaper | generated by `textures.py` | ours, no outside material |
| Metal, plastic, glass materials | Blender Principled BSDF plus procedural noise bump | ours |
| Studio lighting and floor | built in `env.py` | ours |

No CC0 texture or model is used yet. If one is added, record its URL, licence and date here. Real teardown photos were looked at for reference only and nothing was copied.
